5 · Spielerverwaltung

Im Modal „Spieler verwalten" (Admin-Bereich):

Neuer SpielerBewerb + Gruppe wählen → Name + PIN eingeben → Hinzufügen
PIN ändernIn der Tabelle auf „PIN ändern" klicken
Spieler löschenAuf „Löschen" klicken → Bestätigung erforderlich
Config speichern→ Änderungen werden in Firebase gespeichert

6 · Ergebnis korrigieren

Der Admin kann jedes Ergebnis bearbeiten, unabhängig vom eingeloggten Spieler.

Schritt 1Als Admin einloggen
Schritt 2Bewerb + Gruppe des Spiels wählen
Schritt 3Spiel finden → „Bearbeiten" klicken
Schritt 4Werte korrigieren → Speichern

Einzel: Im Bearbeiten-Modal wird der Spielstand je Satz erfasst (Satz 1/2/3, Games); Gewinnsätze, Sieger und gewonnene Games berechnet die App daraus neu. Spiele mit „⚠ Spielstand nachzutragen" haben noch keine Satz-Spielstände – hier zählen die Games erst nach der Nacherfassung.
